# Engineering Principles

I care about more than making something "work".

```text
Good software
    ↓
Clear architecture
    ↓
Predictable state
    ↓
Useful UX
    ↓
Offline resilience
    ↓
Performance
    ↓
Maintainability
    ↓
Real users
```

Some principles I actively follow:

* **Feature-first architecture**
* **Clean separation of concerns**
* **Reusable components**
* **Offline-first where appropriate**
* **Minimal unnecessary dependencies**
* **Responsive interfaces**
* **Accessible UX**
* **Meaningful Git history**
* **Documentation that developers can actually use**
